# Capturas de pantalla

Las imágenes del README son capturas directas de Tervia 0.2.0-alpha en Windows, a
1360 × 768. Muestran la ventana real de escritorio y no se han recreado como mockups.

En las cuatro capturas no hay una TV seleccionada. Por eso el editor enseña tarjetas de
ejemplo y deshabilita las acciones que requieren una TV compatible conectada. Las
capturas representan la aplicación de Windows, no la salida de una televisión.

La captura de la pantalla de una TV Android/Google/Fire TV compatible está disponible
bajo demanda mediante ADB. No se declara compatibilidad física hasta probar cada modelo
y firmware.
