# Capturas de pantalla

El README incrusta capturas reales de la aplicación WinUI ejecutándose en un escritorio
Windows. No se han retocado ni recreado como mockups. El tema es el que tenía Windows al
tomar cada captura.

Estas capturas muestran la aplicación de escritorio; **no representan la imagen interna
de una TV**. La captura de pantalla de televisores físicos no está implementada en esta
alpha y no se publicarán imágenes de TV como si las hubiera producido Tervia.
