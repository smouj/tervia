# Capturas de pantalla

Los PNG de esta carpeta son capturas reales de la interfaz anterior al editor en vivo de
Inicio de TV incluido en 0.3.0-alpha. Se conservan como referencia, pero no documentan
la apariencia actual de la app. La captura actual de Windows está pendiente; no se usan
mockups para presentarla como una captura del producto.

Estas imágenes no proceden de una televisión. La compatibilidad física del launcher se
documenta por modelo y firmware en `docs/COMPATIBILITY.md`.
