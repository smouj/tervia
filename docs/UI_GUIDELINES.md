# UI guidelines

Tervia is a Windows utility, not a marketing page.

- Compact, technical layout with high information density.
- Native WinUI 3 controls, system theme, no custom chrome.
- One selected television is always visible in the header together with its
  platform and connection state.
- Sections appear only when supported; unsupported capabilities are explained
  instead of shown as broken buttons.
- Destructive actions use the standard Windows error colour and always name the
  television they affect.
- Keyboard navigation, screen reader labels and 200% DPI must work.
- No neon gradients, no fake gauges, no "boost" language.
